# Twenty candidate innovations, with implementation status

These are product directions, not twenty claims of invention. Many concepts already exist elsewhere in the agent ecosystem. Every item states what this release **actually** contains.

| Direction | Status | Current evidence / limitation |
|---|---|---|
| Agent Time Machine | PARTIAL | SQLite event timeline; no restoration of prior file revisions |
| Autonomous Failure Investigator | PLANNED | Existing local diagnostic engine, no independent failure-investigation agent workflow |
| Token Budget Intelligence | PARTIAL | Strict per-role LLM step limit, no provider token-budget forecast |
| Capability Negotiation | PARTIAL | Keyword-based role selector and action capability permissions, no multi-agent negotiation |
| Evidence-First Completion | IMPLEMENTED | Edited tasks require a fresh passing check; regression tests |
| Project Digital Twin | PARTIAL | Static Python symbol index and import graph, not an incremental multi-language twin |
| Predictive Build Failures | PLANNED | Conventional changed-file check selection only |
| Multi-Agent Conflict Resolver | PARTIAL | Safe sequential DAG and exact-match edits, no concurrent worktree merge |
| Live Architecture Map | PLANNED | Import graph available as JSON, no interactive architecture graph |
| Context Relevance Compiler | PARTIAL | Deterministic literal search with hard context-char budget |
| Agent Reliability Profiles | IMPLEMENTED | Success/failure summaries from recorded sessions |
| UX Reality Check | PLANNED | No automated browser accessibility/regression suite |
| Model-Free Work Continuation | IMPLEMENTED | Verification, tools, indexing and inspection run without a model |
| Tool Permission Simulator | IMPLEMENTED | `intelligence permissions` previews permitted/denied actions |
| Duplicate Task Detection | IMPLEMENTED | Original TaskStore canonical input-hash dedup for queued tasks |
| Regression Guardian | PARTIAL | Check gate after edits; no automated verified rollback |
| Explainable Agent Delegation | PARTIAL | Keyword scoring available in role selector, detailed explanation not surfaced |
| Resource-Adaptive Swarm | PLANNED | Bounded sequential DAG; no dynamic CPU/RAM-aware scheduling |
| Reproducible Session Capsule | IMPLEMENTED | ZIP of verification metadata/hashes, without code or credentials |
| Self-Improving Workflow Library | PLANNED | Curated skill manifests only, no learning or approval loop |

No 'PLANNED' entry is counted as implemented. PARTIAL items are intentionally excluded from claims of full feature completeness.
