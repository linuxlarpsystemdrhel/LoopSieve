# LoopSieve — подготовка публичной альфы

20 ноября 2026 года. В проверяемый набор входят исходники, тесты, документация, логотип и офлайн-бенчмарки. Веса модели удалены из проекта. Опциональный клиент локального инференса теперь требует явную конфигурацию модели пользователя.

- Git игнорирует виртуальные окружения, кеши, журналы, локальное состояние, файлы весов, локальные настройки и распространённые файлы с учётными данными. Публичные модельные примеры используют заполнитель `local-model` для сервера пользователя.
- Правила упаковки исключают локальные файлы и используют явный список публикуемых результатов экспериментов.
- Предыдущий инженерный отчёт и результаты экспериментов для снятого профиля лежат в игнорируемом локальном архиве `.private/release-history/`.
- Прошёл полный набор из 161 теста. Локальный инференс проверен HTTP-фикстурами. Отдельная модель на этом этапе не скачивалась.

Публичный снимок проверяется отдельно от локальных данных. Правила игнорирования относятся к новым добавлениям. При использовании существующей Git-истории уже отслеживаемые файлы требуют отдельной проверки индекса.
